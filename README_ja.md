**現在のバージョン：1.0**（Steam ワークショップ、または zip：`ElinTogether-independence.zip`）。

> **公式サーバー・公式Discordはまだありません。** Elin Together には現在、公式の公開サーバーも公式Discordもありません。プロジェクトの関係者がお金、パスワード、Steamのログイン情報を求めることは絶対にありません。MODの名前でそれを求める人は私たちではありません。MODとその更新は、このページとSteamワークショップでのみ公開されています。

[Elin](https://store.steampowered.com/app/2135150/Elin/) のマルチプレイ MOD、[Elin Together](https://github.com/ElinTogether/ElinTogether) の改造版です。目的はひとつ：**ゲーム内で、ホストと他のプレイヤーの違いをなくすこと**。各自が好きな場所へ、自分の仲間・クエスト・名声・お金とともに行き、ワールド（ストーリー、拠点、ギルド）は共有のままです。ワールドそのものも、特定のプレイヤーの PC に置いておく必要がなくなりました。

元の MOD は、パーティ全員をホストのマップに留め、他のプレイヤーをホストの仲間として扱います。元の作者は、別々のマップを対象外としています。このフォークは、それを試す場所です。MOD 自体の功績はすべて元の作者にあります（[クレジット](#クレジット)を参照）。

> **状態：1.0、ただし制限あり。** Elin の Nightly ブランチ向けにビルドされています。大部分はゲーム内の自動テストで確認しています（1 台の PC で 2〜5 個のゲームウィンドウ、負荷は最大 50 人のシミュレートされたプレイヤーで測定）。中心部分は小さなグループが実際に遊びました。1.0 には**本物の 2 台の PC の間では一度も遊んでいない部分**があり、リリースノートと下の記述に明記しています。先にセーブのバックアップを取ってください：`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin`

> より詳しい説明（仕組み、正式リリースまでに残っていること）は [English](README.md) または [Français](README_fr.md) 版にあります。

> **日本語対応。** ゲーム内の MOD の表示（メニュー、設定とそのツールチップ、メッセージ、更新履歴）は日本語・英語・中国語に対応しています。ゲームの言語を日本語にすると日本語で表示されます。

## 変わること

### 誰でも好きな場所へ

- **独立した移動。** プレイヤーはホストなしで別のマップへ行けます。マップとそこでの行動は保存され、離れている間も進行は 1 分ごとに保存され、チャットはマップをまたいで使えます。
- **共有マップ。** 相手がホストでもそうでなくても、他のプレイヤーのマップに合流できます。マップを預かっているプレイヤーが離れると、別のプレイヤーが引き継ぎます。
- **誰も連れ回されない。** ホストがマップを移動しても、他のプレイヤーはその場に残ります。マップには入口から入り、ホストの上へテレポートされることはありません。
- **各自のペースで。** モンスターは、ホストのペースではなく、戦っているプレイヤーが動いたときに動きます。ゲストもホストと同じように滑らかに歩けます。
- **自分の時間は自分のもの。** ベッドに入ったらすぐ眠ります。十分な人数が同時に眠ったときに、ワールドの夜が明けます（ホストが選びます：全員、半数、または一人）。席を離れているプレイヤーは、もう夜を引き止めません。他のプレイヤーが旅や睡眠をすると日付は進みますが、自分の空腹は増えず、食べ物は腐らず、クエストの期限も動きません。
- **大きなワールド。** 誰もプレイしていないときは時間を止められ（一人で預かっているマップは、そのプレイヤーが離れている間止まります）、長い不在は 1・3・7 日の段階で追いつきます（ホストが選びます）。クエストは不在のプレイヤーを待ちます：戻ったプレイヤーの期限には、その間にワールドが過ごした日数が加わります。ワールドの全プレイヤーが冒険者ランキングに載ります。
- **生きているワールド**（ホストの選択、初期状態はオフ）。ワールドの日付が現実の時間に沿って、ホストが選んだ速さで進みます：現実の 20・40・60・120 分で 1 日。プレイヤーが動いていても止まっていても同じです。誰もプレイしていないと止まり、ワールドの夜は朝まで進みます。各プレイヤー自身の行動は、これまでどおり自分のターンで進みます。

### プレイヤーごとのもの

- **仲間**は、勧誘したプレイヤー（会話、モンスターボール、騎乗動物、買った動物、どの方法でも）についていき、一緒に移動し、そのプレイヤーの仲間の上限にだけ数えられ、そのプレイヤーの指示に従います。
- **ランダムクエスト、名声、カルマ。** 各自 5 件のクエストと、その報酬。犯罪も同じです：悪事を働いたプレイヤーがカルマを失い、衛兵はそのプレイヤーだけを追います。
- **お金。** 出荷の売上は、出荷箱にアイテムを入れたプレイヤーのものです。ゲストは自分のお金で請求書を払います。
- **自分のキャラクター。** 参加すると、前に遊んでいたキャラクターに質問なしで戻ります。新しいプレイヤーは、ゲームのキャラクター作成画面で自分のキャラクターを作ります。ホストは、ソロのセーブのキャラクターを連れてくることを許可でき、さらに**キャラクターをソロのセーブへ連れ出す**ことも許可できます：キャラクターはそこで遊び、一度だけ戻ってきて（バッグ、お金、名声も一緒に）、その間このワールドでは「外出中」と表示されます。プレイヤーごとのキャラクター数に上限があり（初期状態は 3、ホストが選びます）、ホストは全員のキャラクター一覧を見て削除できます。
- **自分のジャーナル。** 各プレイヤーは、旅やワールドのコピーをまたいで、自分のメッセージ履歴と記録（掘った数、死亡、眠った夜）を保ちます。ホストのものは表示されません（ホストのチェックボックス、初期状態はオン）。
- **自分の設定。** ウィンドウ、自動戦闘、バッグの整理、仲間への指示は、マップを移動しても再接続しても自分のものです。
- **自動戦闘は自分の側を守る。** ゲームの自動戦闘は、それを使ったプレイヤーとその仲間を致命的な一撃から救います（そのプレイヤー自身の戦術スキルとスタミナで）。以前は、ホストの自動戦闘が全員を守り、ゲストの自動戦闘は誰も守りませんでした。誰のものでもない仲間は、誰にも守られません。
- **自分の称号。** 自分で選んだ称号（異名）は自分のものです。ゲストがホストの称号をもらうことはなくなり、セッションをまたいでも自分の称号が残ります。

### 全員でひとつのワールド

- **ストーリー。** ストーリークエストはひとつのログにあり、誰でも開始・進行・完了できます。見たダイアログ、キーアイテム、借金も共有です。
- **拠点。** ゲストもホストと同じように建築できます（床、壁、家具、採掘、掘削、伐採、ゾーン、地形ツール）。一方が建てたものは、すぐにもう一方にも見えます。研究、拠点のスキル、政策、住民、コンテナの設定は、どのプレイヤーでも管理できます。ホストは、チェックボックスひとつで拠点の管理を自分だけにできます。
- **ギルド、好感度、カード図鑑、銀行。** ギルドへの加入はグループ全体に有効で、住民の好感度は全員で同じです。誰かが集めたカードは全員の図鑑に入り、銀行はどこでも同じ中身を表示します。
- **ダンジョンクエスト。** 専用のゾーンを持つクエストは、どのプレイヤーでも受けられます。一人が出発すると、もう一人に同行するかどうかの「はい／いいえ」が表示されます。ゾーンは共有、報酬はクエストを受けた人のものです。
- **マップの音楽。** マップのプレイリストウィンドウで選んだ音楽は、そのマップにいる全員で同じです。
- **プレイヤー同士。** 取引ウィンドウ（双方がアイテムとお金を出し、双方が確定。装備中のアイテムは取引すると外れます）、誰も死なず何も失わない決闘（自分のメニューに*降参*があります）、そして決闘以外では互いを倒せないこと。さらに 2 つのオプション（ホストのチェックボックス、初期状態はオフ）：ホストとの決闘をそのために作られた**アリーナ**で行うことと、双方が**ゴールドを賭ける**こと（勝者が総取り。勝者がいない決闘では返金、降参すると賭け金を失います）。
- **冒険者との決闘**は、どのプレイヤーでもホストと同じようにできます：決闘中は冒険者が街を離れ、次の決闘までの 1 週間は全員で同じで、勝利は記録され、報酬は冒険者自身から出ます。
- **仲間と遊ぶパーマデス**（ホストのオプション、初期状態はオン、パーマデスのワールドのみ）：死んだプレイヤーはゲームが終わる代わりにワールドで待ち、他のどのプレイヤーでも、バーテンダーでゲームの料金を払って蘇生できます。ホストが死んだときも、何も削除されません。

### チーム（任意）

初期状態ではオフです（ホストのチェックボックス *Teams*）。ホストがオンにすると、プレイヤーはチームを作れます。チームごとに自分たちの土地、チェスト、建物、ドアがあり、作った人には土地の権利書が渡され、ホストが許可すればチーム間の PvP もできます。他のチームのチェストは、クラフトにも使えません（ホストも拒否します）。新しいプレイヤーはスポーンゾーンに現れます：ゲーム開始時の草原、ホストのマップ、または名前か番号で指定したゾーン。チェックボックスをオフにすれば、何も変わりません。さらに 3 つのホストのチェックボックスがあり、どれも初期状態はオフです：

- **チームごとに自分の土地の税を払う。** チームごとに毎月 1 枚の請求書。自分の土地だけが対象で、メンバーの最高の名声で計算されます（誰のものでもない土地：放浪者の請求書）。未払いの請求書はチームごとに数え、そのチームのプレイヤーだけがカルマを失います。
- **チームごとのストーリーのジャーナル**：チームが関わったメインクエストの最も進んだ章を、チームカードに表示します。ストーリー自体はワールドのものです。
- **プレイヤーまたはチームごとの学習**（チームなしでも使えます）：レシピ、クラフトの記録、カード図鑑はチームのものです（チームは一冊を共有し、チームのないプレイヤーは自分の一冊を持ちます）。他のプレイヤーが読んだスクロールはその人のゲームでだけ習得され、討伐は倒した人のチームに数えられ、ストーリーが与えるレシピは全チームに届き、プレイヤーの既知の内容はチームを移っても付いてきます。

### プレイヤーまたはチームごとのストーリー（実験的）

初期状態ではオフです（ホストのチェックボックス *プレイヤーまたはチームごとのストーリー*）。**公式サーバーでは常にオン**です。各プレイヤーが自分のペースでメインストーリーを進めます（アッシュのクエスト、ニメルの探索とその会話）。チームはひとつのストーリーを共有し、チームのないプレイヤーは自分のストーリーを持ちます。オンにすると、全員がワールドの現在の進行から始めます。ファリスは最初の拠点にだけ加わります。他の人がすでに突破したニメルの階に着いたプレイヤーやチームは、そこから続きます。ストーリーの報酬はプレイヤーごとに一度だけ支払われます。セーブにはホスト自身のストーリーが残ります：チェックボックスを外すか、MOD なしでセーブを開くと、ワールドはそれを引き継ぎます。オフ：従来どおり全員でひとつのストーリー。

### 時間と設定をシンプルに

- **ワールドマップの時間、3 つのモード**（ホストの選択）：*共有時計*（時計はひとつ、ワールドマップは誰も待たない）、*一緒に旅する*（グループがワールドマップを一体で移動し、読み込み中のプレイヤーを待つ）、*個人のペース*（各自のペースで旅し、合流したときに他の人が追いつく）。
- **設定を整理。** 上部にプリセットとわかりやすい選択肢（「おすすめの協力プレイ」「従来のホスト主導」、またはカスタム）、個別のチェックボックスは*詳細設定*にまとめ、各項目の下に説明を表示し、無効な項目はグレーアウトし、「おすすめに戻す」と「元に戻す」を用意しました。フレンドには読み取り専用の「このワールドのルール」が表示されます。同じページはゲーム標準の MOD 設定ページにもあります。

### ワールドが全プレイヤーを見る

- **ワールドの内容はホストだけでなく全プレイヤーが基準。** 街の掲示板（名声の条件、危険度、報酬）、店の在庫と特別な棚、マップのスポーン、樽、熟成棚、母乳は、ホストのキャラクターだけでなくマップ上のプレイヤーに従います。
- **拠点と街の暮らしを全プレイヤーに。** 襲撃、幸運の月、プレイヤーと過ごした日数、農場の雨は全プレイヤーを数え、住民・僧侶・ネフィアのボス・噂・石投げは各プレイヤーとそのカルマを基準にします。ボス撃破で到達階層がマップ上の全員に記録され、召喚物は自分の主人に従います。
- **各プレイヤーの運勢・日記・カウンター**（運勢のロール、再構築レベル、日記、秘蔵品、既知のレシピ、スケッチ、曲、復活地点）はそのプレイヤーのもので、ワールドのコピーをまたいで保たれます。仲間の勧誘費用は一度だけ支払われます。
- **プレイヤーごとの自動戦闘**、戦闘ルールの統一（弱点、召喚物の下限、投擲の成長、速度）、ゲーム標準ルールの決闘。
- **難易度はプレイヤーに従う。** クエストの難易度は、クエストを受けたプレイヤーに従います。

### ゲストもソロのプレイヤーと同じように遊べる

ホストにできることがゲストにもできるようにする、数十の修正：死亡と遺言、神の贈り物、祭壇、罠、魔法書、治療師、祝福、出資、ルーン、自動収納、手に持った道具、Kettle でのコピー依頼、バーテンダーでの仲間の蘇生、ホストの画面に開いてしまっていたウィンドウ、係留柱、ゲストの仲間が罠にゲストの拾い集めの特技を使うこと、クエストを終えたゲストのそばに立つストーリーの住民、ゲストにも読める「一日が終わる」、ゲストの「常に整頓」でゲームが固まる問題、マップを離れている間に抜けたゲストが接続切れと見なされなくなったこと…。新しい修正：ゲストの防衛クエストの角笛がホストのゲームで鳴る、移転の権利書で拠点がホストのワールドで全員分移動する、ゲストのワールドマップの旅がホストの街に入ったときに支払われる、好戦の特技と虚無のボス階がプレイヤー自身の側を読む、ナスの妖精のダンジョンと階段が、そこにいるプレイヤーのナスを探す、料理クエストが受けた人の自作の料理を求める、保存したパーティ設定とキャラクターシートの合計特技がワールドのコピーをまたいで本人のものになる、拠点のメールが各プレイヤーのものになる、結婚式が拠点の住民を席に着かせる、実績がそれに関わるプレイヤーに付く、遭遇が訪れた人自身のゲームで決まる、など。また、各ゲストのストーリーシーン、バッカーのリスト、Churyu の数は、ワールドのコピーをまたいで各自のものとして保たれます。完全な一覧は開発者のメモに保管されていて、公開していません。

### ワールドはホストの PC に依存しない

- **デポがワールドを保管します**：プライベートな GitHub リポジトリ、共有フォルダ、または小さなサーバーアプリ。最初に来たプレイヤーがワールドを取り出してホストし、セーブのたびにデポへ戻り、そのプレイヤーが抜けたら次の人が引き継げます。[デポ](#デポでワールドをオンラインに保つ)を参照。
- **持ち主が変わるワールド。** ワールドを引き継いだ人は自分のキャラクターで遊びます。前のホストは、参加するときに自分のキャラクターに戻ります。すでに誰かがホストしている場合は、コピーを開く代わりにそのゲームへ案内されます。
- **ホストは何もしなくてよい。** 他のプレイヤーがいる間、ワールドは 2 分ごとに自動保存されます。すでに共有されているワールドは、読み込むとすぐ Steam フレンドに公開されます。
- **接続が切れても大丈夫。** 接続を失ったゲストは、自動でゲームに戻ります（3 分間再試行）。
- **ゲーム同士の食い違いを防ぐ。** 回線が詰まってもメッセージを捨てません。2 秒ごとにマップごとの数値を比べ、食い違いが続くマップはその場で読み込み直します。
- **より安全なネットワークデータ**（元の MOD から取り入れ）。他のゲームから送られてくるものは、ゲームとその MOD 自身のデータの種類としてしか読み込まれず、それ以外は拒否されます。
- **専用サーバー。** Minecraft のサーバーのように、誰も操作しない Elin がワールドを動かし続け、Steam またはアドレスで参加できます。1 時間ごとにワールドをバックアップし、*Elin Together Server* アプリは、クラッシュしたときの再起動、バックアップの復元、Windows と同時の起動を行い、プレイヤー、管理ログ、リアルタイムのグラフを表示します。
- **ホストがきれいに抜ける。** ホストが完全に終了するとき、ゲストは固まった画面で待たされる代わりに、その旨を知らされます。

### 公開サーバー：管理と安全

- **モデレーション。** 理由を付けたキック（そのプレイヤーは数分間戻れません）、Steam アカウント単位の BAN とミュート（ワールドに保存）、ホストが任命する管理者（*Players* タブに Kick、Mute、Ban ボタンがあります）、そして *Members only* モード。すべての操作は `ElinMP/Logs/admin.log` に書かれます。専用サーバーは、同じ命令をアプリまたは `ElinMP/server.cmd` から受け取ります。
- **公式サーバー。** タイトル画面に、Elin Together アカウントの公開ゲームが公式として最初に表示され、参加人数も出ます（開いていないときは控えめな一行）。最大 100 人です。そのエントリーには署名があるため、「Elin Together」と名乗っているだけのゲームは公式として表示されません。公式サーバーは持ち込まれたキャラクターを拒否し、常に各プレイヤーごとのストーリーで動きます。
- **改造されたゲームへの対策。** ホストは、ゲストにその権利がないこと（他のプレイヤーのアイテムやキャラクター、でっち上げのお金やアイテム、他人の名前でのチャット）を拒否します。公開ゲームと専用サーバーでは常にそうで、それ以外では *Refuse acts on what others own* のチェックボックスで決まります。細工されたパケットやマップで、ホストをクラッシュさせたりコードを実行させたりすることはできなくなりました。ダイアログの結果、共有クエスト、ストーリーの贈り物、個人クエストの報酬、拠点の資源、街への出資、ワールドの時間と知識のメッセージ、吹き出し、合図、個人宛の発言は、すべてホスト側で確認され、確認に失敗すれば拒否されます。また、他人のマップにプレイヤーが招かれるのは、チームメイトか保証されたプレイヤーによる場合だけです。
- **多人数。** 各プレイヤーには自分のマップに関わるものだけが送られ、同時に到着したプレイヤーはワールドのコピーをひとつ共有し、スナップショットには変化したキャラクターだけが入り、負荷は最大 50 人のシミュレートされたプレイヤーで測定されています。
- **ゲーム内からバグ報告。** *クライアント設定 → ヘルプ → 開発者にバグを報告*：本物のテキストボックス（Enter で改行、Ctrl+Enter で送信）で、報告には画面の直近 30 秒の動画とログが付きます。GitHub の公開 issue には、書いた内容、Steam 名、バージョン、動画が入ります。ログ（Steam ID を含みます）は開発者だけが非公開で保管します。送れないときは、入力済みの GitHub のページが開きます。

### 全員が同じ MOD を、サブスクライブなしで

- **ゲームの MOD は自動で取得されます。** 参加するときにワークショップの MOD が足りなければ、サブスクライブせずにダウンロードされ、Elin がそのゲームの MOD で一度だけ再起動して、ゲームに戻してくれます。次に起動したときは、自分の MOD リストに戻ります。[MOD](#mod) を参照。
- **Elin のバージョンが違っても一緒に遊べます。** 全員で同じでなければならないのは MOD のバージョンだけです。Elin のバージョンが違うプレイヤーは、警告のうえ参加できます。

これらのほとんどは**ホスト側のチェックボックスまたは選択肢**です。チェックを外すと、MOD は元の動作に戻ります。[ホストの設定](#ホストの設定)を参照。

## インストール

Steam の Elin を **Nightly** ブランチ（Steam → Elin を右クリック → プロパティ → ベータ）にして、[YK Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3400020753) を入れてください（下のワークショップでの導入なら一緒に入ります）。MOD の入手方法は 2 つあり、どちらも同じ 1.0 です。どちらか一方だけを使ってください。

**A. Steam ワークショップ（いちばん簡単、自動で更新）**

1. ワークショップで [Elin Together](https://steamcommunity.com/sharedfiles/filedetails/?id=3773298709) をサブスクライブします。
2. Steam から Elin を起動し、ゲームの MOD 一覧で *Elin Together* にチェックが入っていることを確認します。ゲームに求められたら再起動します。

**B. zip（[Releases ページ](https://github.com/jeanfreger/elin-together-independence/releases)にもあります）**

YK Framework を入れた状態で Elin を一度起動して、閉じてください。

1. `ElinTogether-independence.zip` をダウンロードします。
2. フォルダごと解凍して `Install.bat` を実行します。Elin を探して MOD をコピーし、ワークショップ版からこの版に切り替えます。
3. Steam から Elin を起動します。

`Uninstall.bat` でワークショップ版に戻せます。何も削除されません。zip には `Install.bat`、`Uninstall.bat`、`Server.bat`、`README.txt` が入っています。インストーラーと説明は英語です（説明には中国語もあります）。現在は Windows 版 zip のみ提供しています。手順は各リリースのページにもあります。zip を使っていて、ワークショップに切り替えたい場合は、先に `Uninstall.bat` を実行してください。

**全員が同じバージョンにしてください。** この MOD は元の Elin Together とは接続できず、このフォークの別のバージョンとも接続できません。各リリースは Elin の特定のバージョン向けにビルドされていて、リリースのタイトルに書いてあります。

**更新**：ワークショップなら Steam が行います。zip なら新しいものをダウンロードして、もう一度 `Install.bat` を実行します。設定は残ります。

## 遊び方

タイトル画面の *Elin Together* ボタン、またはゲーム中に Esc → Mods → Elin Together で MOD のパネルを開きます。タブは「ロビー」「サーバー設定」（ホストのルール）「クライアント設定」で、セッションが始まると「セッション情報」が加わります。

- **ホストする。** 土地を確保済みのセーブを読み込み、「ロビー」タブで「サーバー起動」を押します。すでに共有されているワールドは、自動で Steam フレンドに公開されます。
- **参加する。** Steam の招待を受けるか、Steam のフレンドリストでフレンドの名前から「ゲームに参加」を選ぶか、「ロビー」タブでゲームを選びます。「アドレスで参加」はサーバー用です。
- **ルール。** ホストが「サーバー設定」で決めます。変更はすぐに全員に適用されます。

## デポでワールドをオンラインに保つ

デポは、共有ワールドを特定のプレイヤーのセーブの外に保管します。これで、グループは誰か一人がいることに頼らなくて済みます。ホストする可能性のあるプレイヤーは、「クライアント設定」で一度だけ設定します：**デポ**と、パスワードやキーがある場合は**デポのキー**。参加するだけのフレンドには、どちらも必要ありません。

| デポ | 必要なもの | 「デポ」の設定 |
|---|---|---|
| プライベートな GitHub リポジトリ | グループの誰か一人の GitHub アカウント。つけっぱなしの PC も、ポート開放も不要。 | `github:所有者/リポジトリ` |
| Elin Together Server（zip の中の `ElinTogetherServer.exe`） | つけっぱなしの PC。Elin のインストールは不要。TCP ポート 55557。 | `アドレス:55557`、または「アドレスで参加」だけ |
| 共有フォルダ | 全員がアクセスできるフォルダ（共有または同期）。 | フォルダのパス |

そのあと、「ロビー」タブで：

- **このセーブをサーバーに置く**（セーブを読み込み済みで、まだ他のプレイヤーに公開していないとき）：そのセーブがデポのワールドになります。
- **サーバーから世界を取り出してホストする**（タイトル画面から）：最新のワールドを受け取ってホストし、他のプレイヤーは Steam で参加します。すでに誰かがホストしている場合、ボタンにその名前が表示され、そのゲームに参加できます。
- セーブのたびにデポへ戻ります（多くても 5 分に 1 回、終了時にもう 1 回）。ホストが抜けたら、誰でもワールドを取り出せます。ホストがクラッシュした場合、ワールドは 3 分後に自動で解放されます。

**GitHub を使う場合**、リポジトリの所有者が：

1. github.com で、このワールド専用の空の**プライベート**リポジトリを作ります（MOD は公開リポジトリを拒否します）。
2. そのリポジトリだけに限定したアクセストークン（fine-grained token）を作り、権限を *Contents: Read and write* にします。
3. **デポ**に `github:所有者/リポジトリ` と書き、**デポのキー**にトークンを貼り付けます。
4. この 2 つを、ホストする可能性のあるフレンドに伝えます。フレンドに GitHub アカウントは不要です。

キーは、各 PC の MOD の設定ファイルに平文で保存されます。開けるのはそのリポジトリだけで、ワンクリックで無効にできます。zip で 20 MB を超えるワールドは拒否されます。GitHub はワールドのすべてのバージョンを残します。これは無料のバックアップになりますが、セーブのたびにリポジトリが大きくなるということでもあります。大きくなったら、削除して新しく作り直してください。デポには、ワールドの MOD リスト `modlist.txt` も保管されます。

**専用サーバー。** `ElinTogetherServer.exe` には 2 つ目のモード「With Elin on this PC: the world runs all the time」があります。Elin がウィンドウなしで裏で動き、プレイヤーはサーバーの Steam ロビー、または「アドレスで参加」（`アドレス:55556`、UDP）で参加します。アプリは、Elin が勝手に止まったら再起動し、1 時間ごとのワールドのバックアップを保持し（停止中にワンクリックで復元）、Windows と同時に起動でき（`--elin <save>`）、モデレーション（キック、ミュート、BAN、全員へのメッセージ）、管理ログ、サーバーの状態（プレイヤー、ネットワーク、メモリ）のページがあります。`Server.bat` は、ゲームウィンドウ付きで同じことをします。Windows のみ。

## MOD

ゲームに参加するとき、またはデポからワールドを取り出すときに、ワークショップの MOD が足りない場合：Steam アカウントは何もサブスクライブしないまま MOD がダウンロードされ、Elin が閉じて、そのゲームの MOD で**一度だけ**再起動し、ゲームに戻してくれます。自分の余分な MOD が参加を妨げている場合は、それらなしで一度再起動します。次に Elin を起動したときは、自分の MOD リストがそのまま戻ります。何かが削除されたり、サブスクライブ解除されたりすることはありません。

- 基準になるリスト：ワールドがデポから来た場合はデポの `modlist.txt`、そうでなければホストの MOD。
- Elin が自動で再起動しない場合は、30 分以内に手動で起動してください。ゲームに戻してくれます。
- 手動で入れた MOD（ワークショップ外）はダウンロードできません。その名前が表示されます。
- 自分の MOD を保ったまま、違いだけ知らせてほしい場合：「クライアント設定」で「ゲームのModを自動で取得する」のチェックを外します。

**これらの MOD はホストが選び、そのコードはあなたの PC で動きます。信頼できる相手とだけ使ってください。**

AutoAct と Dynamic Riding に対応しています。その他の MOD の互換性は、元の MOD と同じです。

## 既知の制限

- **実際に遊んだのは小さなグループひとつだけです。** 最近の変更の多くは、テスト環境でしか動かしていません。リリースノートやコミットメッセージの「未プレイ」は、文字どおりの意味です。
- **ホストが抜けたりクラッシュしたりしても、ゲストが自動でワールドを引き継ぐことはありません。** （「引き継ぎ」のチェックボックスはありますが、本物の 2 台の PC の間で試すまでオフのままです）。誰かが手動でデポから取り出します。
- **ワールドの日付はひとつ**です。ワールドマップの旅が日付をどう進めるかは、ホストが選ぶ*ワールドマップの時間*のモードによります。空腹、腐敗、期限などの影響はプレイヤーごとです。
- 自分だけの夜の数秒間、プレイヤーは攻撃されることがあります。他のプレイヤーにとってワールドは動き続けています。
- ホストとゲストがマップで再び合流すると、ゲストの画面が読み込み直されます。チェックボックス「ホストと合流してもワールドを読み込み直さない」で避けられますが、新機能のため初期状態はオフです。
- ホストの画面では、歩いているゲストが 3 マスずつ飛ぶように動くことがあります。
- マップを預かっているプレイヤーに拒否されたプレイヤーは、その場に留まります。
- **多人数**：1 台の PC で 5 つのゲームウィンドウと、最大 50 人のシミュレートされたプレイヤー（プロトコルを話す負荷ツール）をテストしましたが、本物のプレイヤーが同時に 3 人を超えたことはありません。人数が多いと、全員が同時に到着したとき、ホストはグループごとに約 0.5 秒から 1 秒止まります。
- 二人でのダンジョンクエストで、ゲストがクエストを受けた場合：「討伐」・収穫・音楽のクエストに対応します。防衛クエストは一人でこなします。
- アリーナと賭けはホストとの決闘にだけあります。ゲスト同士の決闘は、その場で、賭けなしで行われます。
- 「プレイヤーまたはチームごとのストーリー」は実験的です：メインストーリーのすべての結末とすべての会話を、複数の本物のプレイヤーで通して遊んだわけではありません。
- **次の項目は、本物の 2 台の PC の間では一度もテストしていません：** ゲーム一覧での公式サーバーのエントリー、同じアカウントの新しい Steam 接続が古いものを置き換えること、アリーナと賭け、各自のストーリー、チームごとの土地税、長時間の生きているワールド、キャラクターのソロセーブへの持ち出し、別の PC でのバグ報告の動画、公開サーバーの新しいチェック。
- MOD の自動取得：ワークショップの MOD のみ。Steam による Elin の再起動、Steam ロビー経由の復帰、Steam Deck や Linux、Mac では、まだ試していません。
- まれな競合がいくつか知られていて、未修正です：二人が同じマスに建築する、旅のあとに騎乗動物が二重になる。

完全な一覧は開発者のメモに保管されていて、公開していません。

## 問題が起きたら

- ホストが関係するチェックボックスを外します。その点について、MOD は元の動作に戻ります。
- 他のプレイヤーと食い違ったプレイヤーは、コンソールで `emp.reconnect_self` と入力します。
- ゲーム内から報告：*クライアント設定 → ヘルプ → 開発者にバグを報告*（書いた内容、画面の直近 30 秒の動画、ログ）。または [このリポジトリの issues](https://github.com/jeanfreger/elin-together-independence/issues) に、各プレイヤーの `Player.log` と `ElinMP/Logs/Session_<日付>.log`（`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin` にあります）を添えて報告してください。このフォークの問題を、元のプロジェクトには報告しないでください。

## ビルド

MOD は `dotnet build ./ElinTogether -c ReleaseNightly` でビルドします。ゲームがインストールされている必要があります。環境変数 `ElinGamePath` にゲームのフォルダを指定してください。`SteamContentPath`（`steamapps/workshop/content`）は `YKFramework.dll` 用です。.NET SDK 11.0 プレビュー、`global.json` を参照。

```ps
git clone https://github.com/jeanfreger/elin-together-independence
cd elin-together-independence
dotnet restore ./ElinTogether --locked-mode
dotnet build ./ElinTogether -c ReleaseNightly
```

リリース用のパッケージ作成とテストツールはリポジトリに置いていません。テスト環境も公開していません。

## 仕組み（簡単に）

元の設計：ホストがワールドをシミュレートし、変化はすべて差分としてクライアントに送られ、クライアントは自分の操作をホストに送ります。このフォークは**ゾーンのリース**を加えました。ホストのマップを離れるプレイヤーは、行き先のマップのリースをホストに求め、自分のワールドのコピーを読み込んで、そのマップを自分でシミュレートします。戻るときと定期的なチェックポイントで、マップをホストに送り返します。基準はホストのままです。リースを持つプレイヤーは、そのマップを他のプレイヤーのためにホストでき、離れるときに引き渡します。

デポは、ひとつのアーカイブにまとめたワールドと、誰がホストしているかを示すロックです。ホストは 1 分ごとにロックを更新し、3 分間更新されなかったロックは空きとみなされます。
