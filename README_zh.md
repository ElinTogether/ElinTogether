> **目前没有官方服务器或官方 Discord。** Elin Together 目前没有官方公共服务器，也没有官方 Discord。项目成员绝不会向你索要钱财、密码或 Steam 登录信息：以本模组名义这样做的人都不是我们。模组及其更新只发布在本页面和 Steam 创意工坊。

这是 [Elin Together](https://github.com/ElinTogether/ElinTogether)（[Elin](https://store.steampowered.com/app/2135150/Elin/) 的多人联机 Mod）的修改版，只有一个目标：**在游戏中，主机玩家与其他玩家没有任何区别**。每个人都可以带着自己的同伴、任务、名声和金钱去想去的地方，而世界（剧情、据点、公会）保持共享。世界本身也不必再存放在某一位玩家的电脑上。

原版 Mod 让整个队伍留在主机的地图上，并把其他玩家当作主机的队友。原作者不打算支持各自独立的地图；本分支就是尝试这件事的地方。Mod 本身的功劳全部属于原作者（见[致谢](#致谢)）。

> **状态：1.0，仍有局限。** 针对 Elin 的 Nightly 分支构建。大部分内容由游戏内自动测试验证（一台电脑上开两到五个游戏窗口，负载用最多 50 名模拟玩家测试），核心部分由一个小团体真正玩过。1.0 中有几部分**从未在两台真实电脑之间玩过**：版本说明和下文已逐项标明。请先备份存档：`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin`

> 更详细的说明（工作原理、正式发布前还缺什么）见 [English](README.md) 或 [Français](README_fr.md) 版本。

> **中文支持。** 游戏内模组的文字（菜单、设置及其提示、消息、更新说明）支持中文、英文和日文。把游戏语言设为中文即可显示中文。

## 改变了什么

### 每个人去想去的地方

- **独立旅行。** 玩家可以不带主机去另一张地图。地图和在那里做过的事都会保留，离开期间进度每分钟保存一次，聊天在所有地图之间都能用。
- **共享地图。** 玩家可以加入另一位玩家所在的地图，不管对方是不是主机。如果掌管地图的玩家离开，由另一位接手。
- **没有人被拖着走。** 主机切换地图时，其他人留在原地。玩家从入口进入地图，不会再被传送到主机身边。
- **各按各的节奏。** 怪物在与它战斗的玩家行动时才行动，而不是按主机的节奏；客机玩家走起来和主机一样流畅。
- **你的时间属于你自己。** 上床后立刻睡觉；当足够多的玩家同时睡着时，世界才会过夜（由主机选择：所有人、一半或一人）。离开键盘的玩家不再拖住夜晚。其他玩家旅行或睡觉时，日期会前进，但你不会更饿，食物不会腐烂，任务期限也不变。
- **大型世界。** 没有人在玩时时间可以停止（独自占着一张地图的玩家离开时，那张地图也会停止），长时间不在后会分步补上（1、3 或 7 天，由主机选择）。任务会等待不在的玩家：回来的玩家，其期限会加上世界在这期间经过的天数。世界里的每位玩家都会列入冒险者排行榜。
- **活的世界**（主机选项，默认关闭）。世界的日期跟随现实时间，速度由主机选择：每 20、40、60 或 120 现实分钟一天，不论玩家行动还是静止。没有人玩时停止，世界的夜晚会一直过到早晨。每位玩家自己的行动仍按自己的回合进行。

### 每位玩家各有各的

- **同伴**跟随招募他的玩家（不管是通过对话、怪物球、坐骑还是买来的动物），与他一起旅行，只计入该玩家的同伴上限，并听从该玩家的指示。
- **随机任务、名声和业力。** 每人 5 个任务，报酬也归自己。犯罪也一样：谁犯的事，谁损失业力，卫兵只追捕那位玩家。
- **金钱。** 出货所得归把物品放进出货箱的玩家；客机玩家用自己的金币支付账单。
- **你的角色。** 加入时直接回到自己之前玩的角色，不会被询问；新玩家在游戏的角色创建画面创建自己的角色。主机还可以允许玩家带来自己单人存档里的角色，并允许他们**把角色带到单人存档**：角色在那里游玩，之后回来一次（背包、金币和名声一并带回），期间它在这个世界里被标记为“外出”。每位玩家的角色数有上限（默认 3，由主机选择），主机还能看到所有人的角色列表并可删除。
- **你自己的日志。** 每位玩家在旅行和世界副本之间，保留自己的消息记录和个人纪录（挖掘、死亡、睡眠次数），而不是显示主机的内容（主机选项，默认开启）。
- **你的设置。** 窗口、自动战斗、背包整理和同伴指示，在每次切换地图和重新连接后都保持是你自己的。
- **自动战斗保护自己人。** 游戏的自动战斗会让启动它的玩家及其同伴免于致命一击（使用该玩家自己的战术技能和体力）。以前，主机的自动战斗保护所有人，客机玩家的自动战斗谁也不保护。不属于任何人的同伴，没有人保护。
- **你的称号。** 你选择的称号（别名）属于你：客机玩家不再得到主机的称号，并且每次游戏都保留自己的称号。

### 所有人共享同一个世界

- **剧情。** 剧情任务在同一个日志里：任何人都可以开始、推进和完成。看过的对话、关键物品和债务也是共享的。
- **据点。** 客机玩家可以像主机一样建造（地板、墙、家具、挖掘、开凿、砍伐、区域、地形工具），一方建造的东西另一方马上就能看到。研究、家园技能、政策、居民和容器设置，任何玩家都可以管理。主机可以用一个复选框把据点留给自己管理。
- **公会、好感度、图鉴、银行。** 加入公会对整个团队有效，居民的好感度对所有人都一样，一位玩家收集的卡片会进入所有人的图鉴，银行在任何地方都显示相同的内容。
- **地下城任务。** 任何玩家都可以接取带有独立区域的任务。一位玩家出发时，另一位会看到「是／否」的询问框，问是否同行：区域是共用的，报酬归接取任务的人。
- **地图音乐。** 在地图的播放列表窗口里为该地图选的音乐，对这张地图上的所有玩家都相同。
- **玩家之间。** 交易窗口（双方放入物品和金币，双方确认；穿戴中的物品交易时会被脱下）、没有人会死也不会损失任何东西的决斗（自己的菜单里有*认输*），以及决斗之外不能互相杀死。另有两个主机选项（默认关闭）：与主机的决斗在**竞技场**进行（为此创建的区域），双方还可以下**金币赌注**，胜者全拿（决斗没有胜者时赌注退还，认输则失去赌注）。
- **与冒险者的决斗**对每位玩家都和对主机一样：决斗期间冒险者离开城镇，下次决斗前的一周对所有人相同，胜利会被记录，奖励来自冒险者本身。
- **与朋友一起的永久死亡**（主机选项，默认开启，仅限永久死亡的世界）：死亡的玩家会留在世界里等待，游戏不会结束，其他任何玩家都可以在酒保处按游戏的价格让他复活。什么都不会被删除，主机死亡时也一样。

### 队伍（可选）

默认关闭（主机选项 *Teams*）。主机开启后，玩家可以组成队伍：每支队伍有自己的土地、箱子、建筑和门，创建者获得一张土地证书，主机允许时队伍之间还可以 PvP。其他队伍的箱子不能使用，连制作时也不行（主机同样会拒绝）。新玩家出现在出生区域：新游戏开始的草原、主机所在的地图，或按名称或编号指定的区域。不开启该选项时，一切如前。另外三个主机选项，默认都关闭：

- **队伍各自缴纳土地税。** 每个队伍每月一张税单，只算自己的土地，按成员的最高名声计算（无主土地：流浪者的税单）。未付税单按队伍计数，只扣该队伍玩家的善恶值。
- **队伍各自保留剧情日志**：记录队伍参与过的主线任务最远章节，显示在队伍卡片上。剧情本身仍属于整个世界。
- **每个玩家或队伍各自学习**（没有队伍时也可用）：配方、制作记录和图鉴归队伍所有（队友共享一套，没有队伍的玩家有自己的一套）。别人读的卷轴只在其自己的游戏里学会，击杀算在击杀者的队伍里，剧情奖励的配方会给到每个队伍，玩家已知的内容会跟着它从一个队伍到另一个队伍。

### 每个玩家或队伍各自经历剧情（实验性）

默认关闭（主机选项*每个玩家或队伍各自经历剧情*），**在官方服务器上始终开启**。每位玩家按自己的节奏经历主线剧情（阿什的任务、尼梅尔的探索及其对话）；一个队伍共享一条剧情，没有队伍的玩家有自己的剧情。勾选时所有人从世界当前的剧情进度开始。法里斯只加入第一个据点；到达已被他人通过的尼梅尔楼层的玩家或队伍从那里继续；剧情奖励每位玩家只领一次。存档保留主机自己的剧情：取消勾选或不带模组打开存档时，世界沿用它。关闭：所有人共享一条剧情，如前。

### 更简单的时间与设置

- **世界地图时间，三种模式**（主机选项）：*共享时钟*（所有人共用一个时钟，世界地图不会等任何人）、*一起旅行*（队伍在世界地图上一同行动，仍在载入的玩家会被等待）和*个人节奏*（每位玩家按自己的节奏旅行，重新会合时其他人再追上）。
- **设置整理。** 顶部是预设和简单的选项（“推荐合作”“经典主机主导”或自定义），单独的复选框都收在*高级*里；每个选项下方有说明，无法生效的从属选项会变灰，并提供“恢复推荐设置”和“撤销”。朋友可以看到只读的“本世界规则”。同样的页面也出现在游戏自带的模组配置页中。

### 世界会参考每一位玩家

- **世界内容参考每位玩家，而不只是主机。** 城镇告示板（所需名声、危险度、奖励）、商店库存和特殊货架、地图刷怪、酒桶、熟成架和母乳，都跟随地图上的玩家，而不再只看主机的角色。
- **基地与城镇生活照顾每位玩家。** 袭击、幸运月、与玩家共度的天数和农场降雨计入每位玩家；市民、牧师、Nefia 首领、传闻和石头围绕每位玩家并依据该玩家的业力；击杀首领所达深度计入地图上的每位玩家；召唤物跟随各自的主人。
- **每位玩家的幸运判定、日记和计数器**（幸运判定、重建等级、日记、藏品、已知配方、草图、曲调、复活锚点）归该玩家所有，并在世界副本之间保留。招募费用只支付一次。
- **按玩家的自动战斗**、战斗规则一致（弱点、召唤物下限、投掷成长、速度），以及采用游戏自带规则的决斗。
- **难度跟随玩家。** 任务的难度跟随接取任务的玩家。

### 客机玩家和单人玩家一样玩

几十项修正，让主机能做的事客机玩家也能做：死亡与遗嘱、神的礼物、祭坛、陷阱、魔法书、治疗师、祝福、投资、符文、自动收纳、手持的工具、在 Kettle 处复制物品、在酒保处复活同伴、原本会在主机画面上弹出的窗口、拴马桩、客机玩家的同伴对陷阱使用该玩家的拾荒专长、站在完成任务的客机玩家身旁的剧情居民、客机玩家读到的“一天结束了”、客机玩家“总是整理”背包导致游戏卡死、客机玩家在离开地图期间退出不再被当作掉线……较新的修正：客机玩家接的防御任务的战角在主机的游戏里响起、搬迁地契会让所有人的据点在主机世界里一起搬迁、客机玩家走进主机的城镇时世界地图旅程会被付费、好战专长和虚空首领层读取玩家自己一方、纳苏的妖精地下城和楼梯会找在场玩家的纳苏、餐点任务要求接任务者亲手做的菜、保存的队伍配置和角色面板的总专长在世界副本之间属于玩家自己、据点的信件归每位玩家、婚礼安排的是据点的居民、成就归属于它所涉及的玩家、遭遇由到访者自己的游戏来掷骰。另外，每位客机玩家的剧情场景、赞助者名单和 Churyu 计数，在世界副本之间都各自保留。完整列表保存在开发者的笔记里，没有公开。

### 世界不再依赖主机的电脑

- **存档仓库保存世界**：私有的 GitHub 仓库、共享文件夹，或一个小型服务器程序。先到的玩家取出世界并主持，每次存档都会送回仓库，他离开后下一位可以接手。见[存档仓库](#用存档仓库让世界保持在线)。
- **世界换人接手。** 接手世界的人玩的是自己的角色；前主机加入时会取回自己的角色。如果已经有人在主持这个世界，你会被送进他的游戏，而不是另开一份副本。
- **主机不用再操心。** 有其他玩家在时，世界每 2 分钟自动保存；已经共享过的世界读取后会自动对 Steam 好友开放。
- **掉线没关系。** 失去连接的客机玩家会自动回到游戏（重试 3 分钟）。
- **各个游戏保持一致。** 线路拥堵时不会丢弃消息。每 2 秒各个游戏会比较每张地图的几个数值，差异持续存在时就地重新载入地图。
- **更安全的网络数据**（取自原版 Mod）。收到其他游戏发来的内容时，只会按游戏及其模组自己的数据类型来读取；其他一律拒绝。
- **专用服务器**，就像 Minecraft 服务器：一个没有人操作的 Elin 让世界一直运行，可通过 Steam 或地址加入。它每小时备份一次世界；*Elin Together Server* 应用会在它崩溃时重新启动它、还原备份、随 Windows 启动，并显示玩家、管理日志和实时图表。
- **主机干净地离开。** 主机彻底退出时，客机玩家会收到通知，而不是对着冻结的画面干等。

### 公共服务器：管理与安全

- **管理。** 踢出并给出原因（该玩家几分钟内不能回来）、按 Steam 账号封禁和禁言（保存在世界里）、由主机任命的管理员（在 *Players* 标签页有 Kick、Mute、Ban 按钮），以及 *Members only* 模式。每个操作都会写入 `ElinMP/Logs/admin.log`；专用服务器从其应用或 `ElinMP/server.cmd` 接收同样的命令。
- **官方服务器。** 标题画面把 Elin Together 账号的公共游戏排在第一位并标为官方，显示在线人数（未开放时只有一行安静的提示）；最多 100 名玩家。它的条目带有签名，所以仅仅自称“Elin Together”的游戏不会被显示为官方。官方服务器拒绝导入的角色，并且始终让每位玩家各自经历剧情。
- **防范被修改的游戏。** 主机会拒绝客机无权做的事（其他玩家的物品和角色、凭空出现的金币或物品、冒用他人名字聊天），在公开游戏和专用服务器上始终如此（否则由 *Refuse acts on what others own* 选项控制）。伪造的数据包或地图不再能使主机崩溃或运行代码。对话结果、共享任务、剧情礼物、个人任务奖励、据点资源、城镇投资、世界时间和知识消息、气泡、标记和私聊，都由主机检查；检查失败就拒绝；玩家只有被队友或已被担保的玩家接待时，才能出现在别人的地图上。
- **多名玩家。** 每位玩家只接收与自己所在地图有关的内容，同时到达的玩家共用一份世界副本，快照只包含有变化的角色，负载最多用 50 名模拟玩家测量过。
- **在游戏内报告问题。** *客户端设置 → 帮助 → 向开发者报告问题*：一个真正的文本框（Enter 换行，Ctrl+Enter 发送），报告会附上你屏幕最后 30 秒的视频和日志。GitHub 上的公开报告包含你写的内容、Steam 名称、版本和视频；日志（含 Steam ID）只有开发者可以查看。无法发送时，会打开已填好的 GitHub 页面。

### 所有人使用相同的模组，无需订阅

- **游戏的模组会自动获取。** 加入时如果缺少创意工坊模组，会在不订阅的情况下下载，Elin 以该游戏的模组重启一次并把你带回游戏。下次启动时恢复你自己的模组列表。见[模组](#模组)。
- **不同的 Elin 版本可以一起玩。** 只有 Mod 的版本必须所有人一致；Elin 版本不同的玩家会在警告后被允许加入。

以上几乎都是**主机一侧的复选框或选项**：取消勾选后，Mod 的行为与原版一致。见[主机设置](#主机设置)。

## 安装

需要 Steam 上的 Elin，并切换到 **Nightly** 分支（Steam → 右键 Elin → 属性 → 测试版），以及 [YK Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3400020753) 模组（下面的创意工坊安装会一并带上）。获取本 Mod 有两种方式，得到的都是同一个 1.0 版本。请二选一，不要两者并用。

**A. Steam 创意工坊（最简单，自动更新）**

1. 在创意工坊订阅 [Elin Together](https://steamcommunity.com/sharedfiles/filedetails/?id=3773298709)。
2. 通过 Steam 启动 Elin，在游戏的模组列表里确认已勾选 *Elin Together*；如果游戏提示，就重启一次。

**B. 压缩包（也在 [Releases 页面](https://github.com/jeanfreger/elin-together-independence/releases)）**

先在装有 YK Framework 的情况下启动一次 Elin，然后关闭。

1. 下载 `ElinTogether-independence.zip`。
2. 解压整个文件夹并运行 `Install.bat`。它会找到 Elin、复制 Mod，并把创意工坊版本切换成本版本。
3. 通过 Steam 启动 Elin。

`Uninstall.bat` 可以切换回创意工坊版本；不会删除任何东西。压缩包里有 `Install.bat`、`Uninstall.bat`、`Server.bat` 和 `README.txt`；安装程序和说明是英文的（说明也有中文）；每个版本页面上也有这些步骤。目前只提供 Windows 压缩包。如果你用过压缩包、现在想改用创意工坊，请先运行 `Uninstall.bat`。

**所有玩家必须是同一个版本。** 本 Mod 不会连接原版 Elin Together，也不会连接它自己的其他版本。每个版本针对一个 Elin 版本构建，写在版本标题里。

**更新**：创意工坊由 Steam 自动更新；压缩包则下载新版并再次运行 `Install.bat`，你的设置会保留。

## 游玩

在标题画面点击 *Elin Together* 按钮，或在游戏中按 Esc → Mods → Elin Together 打开 Mod 面板。标签页有「大厅」「服务器设置」（主机的规则）和「客户端设置」，开启联机后还有「会话信息」。

- **开主机。** 加载一个已有领地的存档，然后在「大厅」标签页点击「启动服务器」。已经共享过的世界会自动对你的 Steam 好友开放。
- **加入。** 接受 Steam 邀请，在 Steam 好友列表里对好友的名字使用「加入游戏」，或在「大厅」标签页里选择游戏。「按地址加入」用于服务器。
- **规则。** 主机在「服务器设置」里设置；修改会立刻对所有人生效。

## 用存档仓库让世界保持在线

存档仓库把共享的世界保存在任何一位玩家的存档之外，这样团队就不必依赖某一个人在线。每位可能主持的玩家在「客户端设置」里设置一次：**仓库**，以及有密码或密钥时的**仓库密钥**。只是加入的好友两者都不需要。

| 存档仓库 | 需要什么 | 「仓库」设置 |
|---|---|---|
| 私有 GitHub 仓库 | 团队里有一位玩家有 GitHub 账号。不需要一直开着的电脑，也不需要开放端口。 | `github:所有者/仓库名` |
| Elin Together Server（压缩包里的 `ElinTogetherServer.exe`） | 一台一直开着的电脑，上面不需要安装 Elin。TCP 端口 55557。 | `地址:55557`，或直接用「按地址加入」 |
| 共享文件夹 | 所有玩家都能访问的文件夹（共享或同步）。 | 文件夹的路径 |

然后在「大厅」标签页：

- **把这个存档放到服务器上**（已加载存档、尚未对其他人开放时）：这个存档成为仓库里的世界。
- **从服务器取出世界并主持**（在标题画面）：你取得最新的世界并主持它，其他人通过 Steam 加入你。如果已经有人在主持，按钮会显示他的名字，并让你加入他的游戏。
- 每次存档都会送回仓库，最多每 5 分钟一次，退出时再送一次。主机离开后，任何人都可以取出世界。如果主机崩溃，世界会在 3 分钟后自动释放。

**使用 GitHub 时**，仓库的所有者：

1. 在 github.com 上创建一个空的**私有**仓库，只用于这个世界（Mod 会拒绝公开仓库）；
2. 创建一个只限该仓库的细粒度访问令牌（fine-grained token），权限为 *Contents: Read and write*；
3. 在**仓库**里填 `github:所有者/仓库名`，把令牌粘贴到**仓库密钥**；
4. 把这两项告诉可能主持的好友。他们不需要 GitHub 账号。

密钥以明文保存在每台电脑上 Mod 的设置文件里；它只能打开这一个仓库，可以一键撤销。压缩后超过 20 MB 的世界会被拒绝。GitHub 会保留世界的每个版本：这是免费的备份，也意味着仓库会随每次存档变大——变得很大时，删除它并新建一个。仓库里还保存着 `modlist.txt`，即这个世界的模组列表。

**专用服务器。** `ElinTogetherServer.exe` 还有第二种模式「With Elin on this PC: the world runs all the time」：Elin 在后台无窗口运行，玩家通过服务器的 Steam 大厅或「按地址加入」（`地址:55556`，UDP）加入。应用会在 Elin 自行停止时重新启动它，每小时保留一份世界备份（停止时一键还原），可以随 Windows 启动（`--elin <save>`），并有管理页面（踢出、禁言、封禁、向所有人发消息）、管理日志和服务器状态（玩家、网络、内存）。`Server.bat` 做同样的事，但带游戏窗口。仅限 Windows。

## 模组

加入游戏或从存档仓库取出世界时，如果你的电脑缺少创意工坊模组：它们会被下载，而你的 Steam 账号不会订阅任何东西；Elin 关闭并以该游戏的模组**重启一次**，然后把你带回游戏。如果是你多出来的模组妨碍加入，Elin 会不带它们重启一次。下次启动 Elin 时，你自己的模组列表原样恢复。不会删除或取消订阅任何东西。

- 参照的列表：世界来自存档仓库时是仓库里的 `modlist.txt`，否则是主机的模组。
- 如果 Elin 没有自动重启，请在半小时内手动启动：它会把你带回游戏。
- 手动安装的模组（不在创意工坊上）无法下载：会显示它的名字。
- 想保留自己的模组、只接收差异提示：在「客户端设置」里取消勾选「自动获取游戏的模组」。

**这些模组由主机决定，其代码会在你的电脑上运行：请只与你信任的人一起使用。**

支持 AutoAct 和 Dynamic Riding。其他模组的兼容性与原版相同。

## 已知限制

- **真正玩过的只有一个小团体。** 最近的很多改动只在测试台上运行过。版本说明或提交信息里的「未实际玩过」就是字面意思。
- **主机离开或崩溃时，没有客机玩家会自动接手世界**（“接手”选项存在，但在两台真实电脑之间试过之前保持关闭）。需要有人手动从存档仓库取出。
- **世界只有一个日期。** 世界地图上的旅行如何推进日期，取决于主机选择的*世界地图时间*模式；饥饿、腐烂、期限等影响按玩家计算。
- 在属于自己的那几秒夜晚里，玩家可能被攻击：世界对其他人仍在继续。
- 主机和客机玩家在一张地图上再次会合时，客机玩家的画面会重新载入。复选框「与主机会合时不重新载入世界」可以避免；它是新功能，默认不勾选。
- 在主机的画面上，行走中的客机玩家可能一次跳三格。
- 被掌管地图的玩家拒绝的玩家，会留在原地。
- **多名玩家**：在一台电脑上测试过五个游戏窗口，以及最多 50 名模拟玩家（一个会说该协议的负载工具），同时在线的真实玩家从未超过三人。玩家很多时，所有人同时到达会让主机每组暂停约半秒到一秒。
- 两人一起做地下城任务，任务由客机玩家接取时：支持「讨伐」、采集和音乐类任务。防御类任务仍由一个人完成。
- 竞技场和赌注只用于与主机的决斗；两位客机玩家之间的决斗仍在原地进行，没有赌注。
- “每个玩家或队伍各自经历剧情”是实验性的：主线剧情的所有结局和所有对话还没有与多名真实玩家完整走过。
- **以下内容从未在两台真实电脑之间测试过：** 官方服务器在游戏列表中的条目、同一账号的新 Steam 连接替换旧连接、竞技场和赌注、各自的剧情、队伍各自缴税、长时间的活的世界、把角色带到单人存档、另一台电脑上的问题报告视频，以及公共服务器的新检查。
- 自动获取模组：仅限创意工坊模组。由 Steam 重启 Elin、通过 Steam 大厅返回、Steam Deck 或 Linux、Mac 上都还没有试过。
- 已知一些罕见的冲突，尚未修复：两位玩家在同一格建造、旅行后坐骑出现两份。

完整列表保存在开发者的笔记里，没有公开。

## 出现问题时

- 主机取消勾选相关的复选框：在这一点上 Mod 的行为会恢复为原版。
- 与其他人不同步的玩家在控制台输入 `emp.reconnect_self`。
- 在游戏内报告：*客户端设置 → 帮助 → 向开发者报告问题*（你写的内容、屏幕最后 30 秒的视频和日志）。或者提交到[本仓库的 issues](https://github.com/jeanfreger/elin-together-independence/issues)，并附上每位玩家的 `Player.log` 和 `ElinMP/Logs/Session_<日期>.log`（位于 `%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin`）。请不要把本分支的问题报告给原项目。

## 构建

Mod 用 `dotnet build ./ElinTogether -c ReleaseNightly` 构建。需要已安装游戏：请用环境变量 `ElinGamePath` 指定游戏文件夹。`SteamContentPath`（`steamapps/workshop/content`）用于引用 `YKFramework.dll`。.NET SDK 11.0 预览版，见 `global.json`。

```ps
git clone https://github.com/jeanfreger/elin-together-independence
cd elin-together-independence
dotnet restore ./ElinTogether --locked-mode
dotnet build ./ElinTogether -c ReleaseNightly
```

版本的打包脚本和测试工具不在仓库里，没有公开。测试环境也没有公开。

## 工作原理简述

原版的设计：主机模拟世界，每个变化以增量的形式发给客机，客机把自己的操作发给主机。本分支增加了**区域租约**：离开主机地图的玩家向主机申请它要去的地图的租约，载入自己的世界副本并自己模拟那张地图。回来时以及在定期的检查点，它把地图送回主机；主机仍然是基准。持有租约的玩家可以为其他玩家主持那张地图，离开时把它交出去。

存档仓库就是打包成一个压缩包的世界，加上一把说明谁在主持的锁。主机每分钟更新一次锁；3 分钟没有更新的锁视为空闲。
